> Ce guide s'adresse aux correcteurs (enseignants) qui souhaitent corriger les copies d'examen depuis une tablette iPad ou Android. Toutes les fonctionnalités de correction sont disponibles sur tablette, avec des gestes tactiles adaptés.

## 1. Prérequis

- **Tablette** : iPad (Safari ou Chrome) ou tablette Android (Chrome)
- **Connexion internet** : Wi-Fi ou 4G/5G
- **Navigateur** : Safari (iPad) ou Chrome (Android), version récente
- **Compte correcteur** : adresse email fournie par l'administration

**Recommandation** : utilisez la tablette en **mode paysage** (horizontale) pour un confort optimal. Le mode portrait fonctionne aussi mais le panneau de barème se retrouve en dessous de la copie.

---

## 2. Se connecter

1. Ouvrir le navigateur sur la tablette
2. Aller sur **https://korrigo.labomaths.tn**
3. Entrer votre adresse email (ex : `prenom.nom@ert.tn`)
4. Entrer votre mot de passe
5. Appuyer sur **Connexion**

Vous arrivez sur le tableau de bord correcteur qui liste vos copies assignées.

---

## 3. Accéder à une copie

1. Sur le tableau de bord, vous voyez la liste de vos copies avec leur statut :
   - **Pret** : copie non encore ouverte
   - **En cours** : correction commencée
   - **Finalisee** : correction terminée
2. Appuyez sur une copie pour l'ouvrir dans l'interface de correction

---

## 4. Comprendre l'interface

L'interface de correction se compose de :

### En mode paysage (recommandé)

```
┌──────────────────────────────────────────────────────────┐
│  ← Retour    COPIE-A3F2    [En cours]    [Finaliser]    │  ← Barre d'outils
├──────────────────────────────────────────────────────────┤
│  ← Préc.   Page 2/4   Suiv. →   ✓V  ✗F  💬 🟨 ❌ ⭐  │  ← Navigation + annotations
│                        │  - [100%] + ↔                  │  ← Zoom
├────────────────────────┼─────────────────────────────────┤
│                        │  Barème                 12/20   │
│                        │  ▶ Partie 1         6 pts      │
│    IMAGE DE LA COPIE   │  ▶ Partie 2        14 pts      │
│                        │    ▶ Exercice 2   3 pts        │
│    (zone de dessin     │      Q2.1  [ 0.5 ] / 0.5      │
│     des annotations)   │      Q2.2  [     ] / 0.5      │
│                        │      Remarque: ___________     │
│                        │                                │
│                        │  Appréciation globale           │
│                        │  ____________________________  │
└────────────────────────┴─────────────────────────────────┘
```

### En mode portrait

La copie occupe la moitié haute de l'écran. Le panneau de barème apparait en dessous et peut défiler verticalement.

## 5. Naviguer dans la copie

### Changer de page

| Geste | Action |
|-------|--------|
| **Balayer horizontalement** (swipe gauche) | Page suivante |
| **Balayer horizontalement** (swipe droite) | Page précédente |
| Boutons **← Préc.** / **Suiv. →** | Navigation page par page |

Le balayage doit être **franchement horizontal** (plus large que haut) et dépasser environ 1 cm pour être reconnu.

### Faire défiler la page

Si la copie est zoomée et dépasse l'écran :
- **Glisser avec 1 doigt** vers le haut/bas pour faire défiler verticalement

---

## 6. Zoomer et dézoomer

| Geste | Action |
|-------|--------|
| **Pincer avec 2 doigts** (écarter) | Zoomer |
| **Pincer avec 2 doigts** (rapprocher) | Dézoomer |
| Boutons **-** / **+** | Zoom par paliers de 10% |
| Bouton **↔** | Ajuster la copie à la largeur de l'écran |
| Appuyer sur le pourcentage (ex: **100%**) | Revenir au zoom 100% |

Le zoom va de **30%** à **300%**. Après un zoom, vous pouvez faire défiler la copie avec 1 doigt pour voir les détails.

## 7. Poser des annotations

Les annotations sont les marques que vous posez directement sur la copie de l'élève : tampons vrai/faux, commentaires, surlignages, signalements d'erreurs.

### Principe général sur tablette

1. **Sélectionner un mode** dans la barre d'outils (tampon, commentaire, etc.)
2. **Appuyer ou tracer un rectangle** sur la copie à l'endroit voulu
3. L'annotation est enregistrée automatiquement

**Astuce** : le bouton sélectionné reste actif (surligné en bleu). Appuyez à nouveau dessus pour le désactiver.

---

## 8. Utiliser les tampons Vrai / Faux

Les tampons permettent de marquer rapidement une réponse comme correcte ou incorrecte.

### Étapes

1. Appuyez sur le bouton **✓ V** (vert) ou **✗ F** (rouge) dans la barre d'outils
   - Le bouton devient actif (surligné)
2. Appuyez sur la copie à l'endroit de la réponse de l'élève
   - Un petit carré vert ✓ ou rouge ✗ apparait instantanément
3. Continuez à appuyer sur d'autres endroits pour poser plusieurs tampons
4. Pour arrêter, appuyez à nouveau sur le bouton **✓ V** ou **✗ F** pour le désactiver

### Ce qu'il se passe

- Un **tap simple** (sans glisser) pose un tampon de taille fixe (petit carré)
- Vous pouvez aussi **tracer un rectangle** en maintenant le doigt appuyé et en glissant, pour un tampon plus grand

---

## 9. Ajouter un commentaire texte

### Étapes

1. Appuyez sur le bouton **💬** (bulle de commentaire) dans la barre d'outils
   - Le bouton devient actif
2. Sur la copie, **tracez un rectangle** en maintenant le doigt et en glissant
   - Un cadre pointillé rouge apparait pendant le tracé
3. Quand vous relâchez, un **éditeur** s'ouvre au centre de l'écran :
   - **Type** : Commentaire (modifiable : Surlignage, Erreur, Bonus, Vrai, Faux)
   - **Contenu** : zone de texte pour saisir votre commentaire
4. Tapez votre commentaire
5. Appuyez sur **Enregistrer**

L'annotation apparait sur la copie avec un cadre bleu et votre texte à l'intérieur.

### Types d'annotations disponibles

| Bouton | Type | Couleur | Usage |
|--------|------|---------|-------|
| 💬 | Commentaire | Bleu | Remarque générale |
| 🟨 | Surlignage | Jaune/Orange | Mettre en évidence un passage |
| ❌ | Erreur | Rouge | Signaler une erreur |
| ✓ V | Vrai | Vert | Réponse correcte |
| ✗ F | Faux | Rouge | Réponse incorrecte |

### Annuler

Si vous changez d'avis après avoir tracé le rectangle, appuyez sur **Annuler** dans l'éditeur.

---

## 10. Utiliser la banque de commentaires

La banque de commentaires conserve automatiquement les annotations que vous avez déjà écrites. Cela vous évite de retaper les mêmes remarques d'une copie à l'autre.

### Ouvrir la banque

1. Appuyez sur le bouton **⭐** (étoile) dans la barre d'outils
2. Un panneau s'ouvre à gauche avec vos commentaires mémorisés

### Insérer un commentaire depuis la banque

Sur tablette, le glisser-déposer n'est pas disponible. À la place :

1. Appuyez sur un commentaire dans la banque
2. Il est automatiquement inséré **au centre de la page courante** comme annotation de type Commentaire

### Fermer la banque

Appuyez à nouveau sur le bouton **⭐** ou sur le bouton de fermeture du panneau.

### Comment les commentaires sont mémorisés

Chaque commentaire et chaque remarque que vous écrivez (d'au moins 5 caractères) est automatiquement sauvegardé dans votre banque personnelle. Plus vous l'utilisez, plus votre bibliothèque s'enrichit.

## 11. Saisir les notes (barème)

Le panneau de barème se trouve à droite (en paysage) ou en bas (en portrait).

### Naviguer dans le barème

Le barème est organisé en **accordéon** :
1. Appuyez sur un exercice (ex: **Partie 2**) pour le déplier
2. Appuyez sur un sous-exercice (ex: **Exercice 3**) pour voir les questions
3. Chaque question affiche un champ de saisie avec le score maximum

### Saisir une note

1. Appuyez sur le champ de note d'une question (ex: `[ ] / 0.5`)
2. Le **clavier numérique** s'ouvre automatiquement (pavé décimal)
3. Saisissez la note (ex: `0.25`)
   - Utilisez le **point** ou la **virgule** comme séparateur décimal
   - La note est automatiquement bornée entre 0 et le maximum
4. La note est **sauvegardée automatiquement** après 0,8 seconde d'inactivité

### Indicateurs visuels

- Champ **vide** : bordure grise
- Champ **rempli** : bordure verte, fond vert clair
- **Note totale** : affichée en haut du panneau et en bas (ex: `12.50 / 20`)
- Si le total dépasse 20 : affichage en **rouge** avec un avertissement

### Astuce clavier

Sur iPad, le clavier peut masquer les champs du bas. L'interface fait défiler automatiquement pour que le champ actif reste visible. Si ce n'est pas le cas, faites défiler manuellement le panneau de barème.

---

## 12. Rédiger les remarques par question

Sous chaque champ de note, il y a un champ **Remarque** optionnel.

1. Appuyez sur le champ "Remarque..."
2. Le clavier s'ouvre
3. Tapez votre remarque (ex: "Bonne méthode mais erreur de calcul")
4. La remarque est **sauvegardée automatiquement** après 1 seconde

### Suggestions

Le bouton **💡** à côté de "Remarque" ouvre un panneau de suggestions contextualisées par exercice. Appuyez sur une suggestion pour l'insérer dans le champ de remarque.

---

## 13. Rédiger l'appréciation globale

L'appréciation globale se trouve tout en bas du panneau de barème, dans un cadre jaune.

1. Faites défiler le panneau de barème jusqu'en bas
2. Appuyez sur le champ "Appréciation globale..."
3. Rédigez votre appréciation (ex: "Bon travail dans l'ensemble. La partie géométrie est bien maîtrisée. Revoir les fractions.")
4. La sauvegarde est automatique après 1 seconde

**L'appréciation est obligatoire pour finaliser la copie.**

---

## 14. Finaliser la copie

Quand toutes les notes sont saisies et l'appréciation rédigée :

1. Le bouton **Finaliser** dans la barre d'outils en haut devient actif (vert)
2. Appuyez sur **Finaliser**
3. Un message de confirmation apparait : "Êtes-vous sûr ? Cette action est irréversible."
4. Confirmez

### Conditions requises

Le bouton Finaliser reste grisé tant que :
- Il manque au moins une note dans le barème
- La note totale dépasse 20
- L'appréciation globale est vide

### Après finalisation

- Le statut passe à **Finalisee**
- La copie devient en lecture seule
- Vous pouvez toujours la consulter et télécharger le PDF final via le bouton **Télécharger**

---

## 15. Supprimer une annotation

Si vous avez posé une annotation par erreur :

1. Les annotations de la page courante sont listées visuellement sur la copie
2. Pour supprimer, vous devez utiliser la liste d'annotations (accessible via le panneau latéral ou en tapant sur l'annotation)
3. Appuyez sur le bouton de suppression (icône poubelle)
4. Confirmez la suppression

---

## 16. Mode paysage vs portrait

### Paysage (recommandé)

- La copie occupe la partie gauche
- Le barème occupe la partie droite (280px)
- Tous les boutons sont visibles sans défiler
- Optimal pour corriger confortablement

### Portrait

- La copie occupe la moitié haute (50% de l'écran)
- Le barème est en dessous (35% de l'écran, défilable)
- Les boutons de la barre d'outils passent sur plusieurs lignes
- Convenable pour les déplacements, moins confortable pour de longues sessions

**Pour basculer** : tournez simplement la tablette. L'interface s'adapte instantanément.

## 17. Utilisation avec un stylet

Si vous disposez d'un stylet (Apple Pencil, S Pen, etc.), le système offre une expérience améliorée :

### Rejet de la paume

Quand vous utilisez le stylet, le système **ignore automatiquement** les touches de votre paume sur l'écran. Vous pouvez poser votre main sur la tablette sans déclencher d'annotations involontaires.

### Comportement du stylet

| Action | Résultat |
|--------|----------|
| Tap du stylet sur la copie | Pose un tampon (si mode tampon actif) ou ouvre l'éditeur |
| Glisser le stylet | Trace un rectangle d'annotation |
| Poser la paume | Ignoré (rejet de paume actif) |

### Mode sans outil sélectionné

Si aucun bouton d'annotation n'est actif :
- **Stylet** : trace quand même un rectangle (ouvre l'éditeur Commentaire par défaut)
- **Doigt** : fait défiler la copie normalement

## 18. Sauvegarde et connexion intermittente

### Sauvegarde automatique

- Les **notes** sont sauvegardées sur le serveur **0,8 seconde** après la dernière frappe
- Les **remarques** sont sauvegardées après **1 seconde**
- L'**appréciation** est sauvegardée après **1 seconde**
- Les **annotations** sont sauvegardées **immédiatement** à la création

### Sauvegarde locale (hors ligne)

Si votre connexion internet est coupée momentanément :
- Un bandeau jaune apparait : "Hors ligne - Les modifications sont sauvegardées localement"
- Vos notes et remarques sont stockées dans le navigateur
- Dès que la connexion revient, tout est synchronisé automatiquement

### Bandeau de synchronisation

| Couleur | Signification |
|---------|--------------|
| Aucun bandeau | Tout est synchronisé |
| Bleu | Synchronisation en cours |
| Jaune | Hors ligne (sauvegarde locale) |
| Rouge | Erreurs de synchronisation (bouton "Réessayer" disponible) |

### Brouillon d'annotation

Si vous êtes en train de rédiger une annotation et que vous quittez la page accidentellement :
- Au retour, un bandeau bleu propose : "Restaurer le brouillon non sauvegardé ?"
- Appuyez sur **Oui, restaurer** pour reprendre ou **Non, supprimer** pour repartir à zéro

## 19. Résolution de problèmes

### La copie ne s'affiche pas

- Vérifiez votre connexion internet
- Rechargez la page (tirer vers le bas dans Safari, ou bouton actualiser)
- Si l'erreur persiste, appuyez sur **Réessayer**

### Le clavier masque les champs de saisie

- Faites défiler le panneau de barème manuellement vers le haut
- En mode portrait, réduisez le zoom de la copie pour laisser plus de place au barème

### Les annotations ne se posent pas

- Vérifiez qu'un mode est actif (bouton surligné en bleu dans la barre d'outils)
- Vérifiez que la copie n'est pas en statut "Finalisée" (lecture seule)
- Essayez avec un geste plus ample (rectangle plus grand)

### Le bouton Finaliser est grisé

Vérifiez que :
- Toutes les questions du barème ont une note saisie (aucun champ vide)
- La note totale ne dépasse pas 20
- L'appréciation globale n'est pas vide

### La zone d'identification est masquée

C'est normal. Le haut de la première page (et de chaque première page de copie) est masqué pour préserver l'anonymat. Seul l'administrateur peut révéler cette zone.

### Problème de zoom intempestif

Si le zoom se déclenche involontairement :
- Évitez de toucher l'écran avec 2 doigts simultanément quand vous ne voulez pas zoomer
- Utilisez les boutons **-** / **+** pour un zoom plus précis

| Geste | Zone | Action |
|-------|------|--------|
| 1 doigt - balayer horizontalement | Copie | Changer de page |
| 1 doigt - glisser verticalement | Copie | Défiler dans la page (si zoomé) |
| 2 doigts - pincer/écarter | Copie | Zoom / Dézoom |
| 1 doigt - tap | Copie | Poser un tampon (si mode actif) |
| 1 doigt - maintenir et glisser | Copie | Tracer un rectangle d'annotation |
| Stylet - tap | Copie | Tampon ou annotation |
| Stylet - glisser | Copie | Rectangle d'annotation |
| Tap | Bouton barre d'outils | Activer/Désactiver un mode |
| Tap | Champ de note | Ouvrir le clavier numérique |
