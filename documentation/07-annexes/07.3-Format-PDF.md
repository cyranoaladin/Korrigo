## 📋 Formats Supportés

### 1. Batch A3 (Recommandé)

**Description** : Copies scannées en A3 recto-verso agrafées

**Caractéristiques** :
- **Format papier** : A3 (297 × 420 mm)
- **Scan** : Recto-verso (double-face)
- **Orientation** : Portrait
- **Résolution** : 300 DPI (recommandé), minimum 150 DPI
- **Couleur** : Niveaux de gris ou couleur (RGB)
- **Compression** : PDF standard (pas de compression excessive)

**Structure** :

```
PDF Batch A3 (88 pages)
├── Page 1 (A3 recto)   → Feuille 1 - Faces 1-2 (étudiant 1)
├── Page 2 (A3 verso)   → Feuille 1 - Faces 3-4 (étudiant 1)
├── Page 3 (A3 recto)   → Feuille 2 - Faces 1-2 (étudiant 1)
├── Page 4 (A3 verso)   → Feuille 2 - Faces 3-4 (étudiant 1)
├── Page 5 (A3 recto)   → Feuille 3 - Faces 1-2 (étudiant 2)
├── ...
└── Page 88 (A3 verso)  → Feuille 44 - Faces 3-4 (étudiant 28)
```

**Exemple réel** : `eval_loi_binom_log.pdf` (88 pages A3, 28 étudiants)

---

### 2. Batch A4 (Support basique)

**Description** : Copies scannées en A4 recto simple

**Caractéristiques** :
- **Format papier** : A4 (210 × 297 mm)
- **Scan** : Recto uniquement (simple-face)
- **Orientation** : Portrait
- **Résolution** : 300 DPI (recommandé)

**Structure** :

```
PDF Batch A4 (88 pages)
├── Page 1 (A4)   → Feuille 1 - Face 1 (étudiant 1)
├── Page 2 (A4)   → Feuille 1 - Face 2 (étudiant 1)
├── Page 3 (A4)   → Feuille 1 - Face 3 (étudiant 1)
├── Page 4 (A4)   → Feuille 1 - Face 4 (étudiant 1)
├── Page 5 (A4)   → Feuille 2 - Face 1 (étudiant 2)
├── ...
└── Page 88 (A4)  → Feuille 22 - Face 4 (étudiant 22)
```

## 📐 Spécifications Techniques

### Dimensions

| Format | Largeur | Hauteur | Pixels (300 DPI) |
|--------|---------|---------|------------------|
| **A3** | 297 mm | 420 mm | 3508 × 4961 px |
| **A4** | 210 mm | 297 mm | 2480 × 3508 px |

### Résolution

| DPI | Qualité | Taille Fichier (estimée) | Usage |
|-----|---------|--------------------------|-------|
| **150** | Minimale | ~20 MB pour 88 pages | Acceptable, OCR dégradé |
| **300** | Recommandée | ~50 MB pour 88 pages | Optimal, OCR précis |
| **600** | Élevée | ~150 MB pour 88 pages | Inutile, surcharge |

**Recommandation** : **300 DPI** (compromis qualité/taille)

### Profondeur Couleur

| Mode | Bits/pixel | Taille Fichier | OCR | Recommandation |
|------|------------|----------------|-----|----------------|
| **Noir & Blanc (1-bit)** | 1 | Très petit | Moyen | ❌ Déconseillé |
| **Niveaux de gris (8-bit)** | 8 | Petit | Bon | ✅ **Recommandé** |
| **Couleur RGB (24-bit)** | 24 | Grand | Très bon | ✅ Acceptable |

## 📄 Structure PDF

### Header Copie (Zone d'Identification)

**Position** : 5 cm depuis le haut de la première page de chaque copie

**Contenu** :
- Nom de famille (MAJUSCULES)
- Prénom (Première lettre majuscule)
- Date de naissance (DD/MM/YYYY)

**Exemple visuel** :

```
┌─────────────────────────────────────────┐
│  Nom : DUPONT                           │ ◄─── 1 cm depuis haut
│  Prénom : Jean                          │
│  Date de naissance : 15/05/2008         │
│                                         │
├─────────────────────────────────────────┤ ◄─── 5 cm (limite header)
│                                         │
│  Question 1 : ...                       │
│                                         │
│  Question 2 : ...                       │
│                                         │
└─────────────────────────────────────────┘
```

**Détection automatique** :
- Korrigo détecte automatiquement zone header (5 cm haut)
- OCR GPT-4o-mini Vision extrait nom + prénom + date
- Fuzzy matching avec CSV étudiants

## 🖨️ Bonnes Pratiques Scan

### 1. Paramètres Scanner

**Scanner recommandés** :
- Canon imageFORMULA
- Fujitsu ScanSnap
- HP ScanJet Enterprise

**Paramètres** :

```
Résolution : 300 DPI
Mode couleur : Niveaux de gris (8-bit)
Format : PDF/A-1b (archivage)
Compression : JPEG (qualité 85%)
Deskew : Activé (redressement auto)
Blank page removal : Désactivé (garder toutes pages)
```

### 2. Préparation Copies Papier

**Avant scan** :

1. **Retirer agrafes** : Scanner détecte mieux les pages individuelles
2. **Aplatir plis** : Éviter ombres OCR
3. **Vérifier ordre** : Pages dans bon ordre
4. **Nettoyer scanner** : Éviter taches/poussière

### 3. Ordre de Scan

**Batch A3 recto-verso** :

```
Pile de copies (top → bottom):
├── Copie Étudiant 1 (2 feuilles A3)
├── Copie Étudiant 2 (2 feuilles A3)
├── ...
└── Copie Étudiant 28 (2 feuilles A3)

Scanner en mode recto-verso automatique (ADF)
→ Génère PDF 88 pages (44 feuilles × 2 faces)
```

**Important** : Scanner doit être configuré en **recto-verso automatique (duplex)**

### Checklist Avant Upload

```bash

# 2. Vérifier résolution
pdfimages -list exam.pdf | head -5

# 3. Vérifier taille fichier
ls -lh exam.pdf

# 4. Vérifier pas de corruption
pdfinfo exam.pdf > /dev/null && echo "PDF valide" || echo "PDF corrompu"
```

### Outils Validation

**PyPDF2 (Python)** :

```python
import PyPDF2

def validate_pdf(pdf_path):
    """Valider PDF avant upload."""
    try:
        with open(pdf_path, 'rb') as f:
            pdf_reader = PyPDF2.PdfReader(f)

            # Nombre de pages
            page_count = len(pdf_reader.pages)
            print(f"Pages: {page_count}")

            # Taille pages (première page)
            page = pdf_reader.pages[0]
            width = page.mediabox.width
            height = page.mediabox.height
            print(f"Dimensions: {width} × {height} points")

            # Vérifier métadonnées
            metadata = pdf_reader.metadata
            if metadata:
                print(f"Producer: {metadata.get('/Producer', 'Unknown')}")

            return True

    except Exception as e:
        print(f"Erreur validation: {e}")
        return False

# Usage
validate_pdf('eval_loi_binom_log.pdf')
```

## 🔧 Correction PDF Problématiques

### Problème 1 : Pages Désalignées (Skew)

**Symptôme** : Pages scannées de travers

**Solution** :

```python
import cv2
import numpy as np
from pdf2image import convert_from_path

def deskew_pdf(pdf_path, output_path):
    """Corriger rotation pages PDF."""
    images = convert_from_path(pdf_path, dpi=300)

    deskewed_images = []
    for img in images:
        # Convertir PIL → OpenCV
        img_cv = cv2.cvtColor(np.array(img), cv2.COLOR_RGB2GRAY)

        # Détecter angle
        coords = np.column_stack(np.where(img_cv > 0))
        angle = cv2.minAreaRect(coords)[-1]

        if angle < -45:
            angle = -(90 + angle)
        else:
            angle = -angle

        # Rotation
        (h, w) = img_cv.shape[:2]
        center = (w // 2, h // 2)
        M = cv2.getRotationMatrix2D(center, angle, 1.0)
        rotated = cv2.warpAffine(img_cv, M, (w, h), flags=cv2.INTER_CUBIC)

        deskewed_images.append(rotated)

    # Sauvegarder PDF corrigé
    # ... (conversion images → PDF)
```

### Problème 2 : PDF Trop Volumineux

**Symptôme** : Fichier > 100 MB (limite upload)

**Solution : Compression** :

```bash
# Ghostscript compression
gs -sDEVICE=pdfwrite \
   -dCompatibilityLevel=1.4 \
   -dPDFSETTINGS=/ebook \
   -dNOPAUSE -dQUIET -dBATCH \
   -sOutputFile=exam_compressed.pdf \
   exam.pdf

# Vérifier nouvelle taille
ls -lh exam_compressed.pdf
```

**Niveaux compression** :

| Paramètre | Qualité | Taille | Usage |
|-----------|---------|--------|-------|
| `/screen` | Basse (72 DPI) | Très petit | ❌ Déconseillé |
| `/ebook` | Moyenne (150 DPI) | Petit | ✅ Acceptable |
| `/printer` | Élevée (300 DPI) | Moyen | ✅ **Recommandé** |
| `/prepress` | Maximale (300+ DPI) | Grand | ❌ Inutile |

### Problème 3 : Pages Inversées

**Symptôme** : Versos à l'envers

**Solution** :

```python
import PyPDF2

def fix_inverted_pages(pdf_path, output_path):
    """Corriger pages inversées (rotation 180°)."""
    pdf_reader = PyPDF2.PdfReader(pdf_path)
    pdf_writer = PyPDF2.PdfWriter()

    for i, page in enumerate(pdf_reader.pages):
        # Pages paires (versos) → rotation 180°
        if i % 2 == 1:
            page.rotate(180)

        pdf_writer.add_page(page)

    with open(output_path, 'wb') as f:
        pdf_writer.write(f)
```

## 🛠️ Génération PDF Test

### Script Génération

**Objectif** : Générer PDF test pour développement

```python
#!/usr/bin/env python3
"""
Générer PDF test avec headers étudiants.

Usage:
    python generate_test_pdf.py --students 30 --pages 4 --output test_exam.pdf
"""

from reportlab.pdfgen import canvas
from reportlab.lib.pagesizes import A4, A3
from reportlab.lib.units import cm
import random

FIRST_NAMES = ['Jean', 'Marie', 'Luc', 'Sophie', 'Pierre', 'Emma', 'Thomas', 'Léa']
LAST_NAMES = ['DUPONT', 'MARTIN', 'BERNARD', 'PETIT', 'DURAND', 'LEROY', 'MOREAU', 'SIMON']

def generate_test_pdf(student_count, pages_per_student, output_path, page_format='A3'):
    """Générer PDF test avec headers."""

    page_size = A3 if page_format == 'A3' else A4
    c = canvas.Canvas(output_path, pagesize=page_size)

    for student_num in range(1, student_count + 1):
        # Générer identité étudiant
        first_name = random.choice(FIRST_NAMES)
        last_name = random.choice(LAST_NAMES)

        # Date naissance (15-18 ans)
        birth_year = random.randint(2006, 2009)
        birth_month = random.randint(1, 12)
        birth_day = random.randint(1, 28)
        dob = f"{birth_day:02d}/{birth_month:02d}/{birth_year}"

        # Pages de la copie
        for page_num in range(1, pages_per_student + 1):
            # Header (uniquement première page)
            if page_num == 1:
                c.setFont("Helvetica-Bold", 14)
                c.drawString(2*cm, page_size[1] - 2*cm, f"Nom : {last_name}")
                c.drawString(2*cm, page_size[1] - 3*cm, f"Prénom : {first_name}")
                c.drawString(2*cm, page_size[1] - 4*cm, f"Date de naissance : {dob}")

                # Ligne séparation
                c.line(1*cm, page_size[1] - 5*cm, page_size[0] - 1*cm, page_size[1] - 5*cm)

            # Contenu page (questions simulées)
            c.setFont("Helvetica", 12)
            y_pos = page_size[1] - 7*cm if page_num == 1 else page_size[1] - 2*cm

            c.drawString(2*cm, y_pos, f"Copie {student_num} - Page {page_num}")

            # Questions simulées
            for q in range(1, 4):
                y_pos -= 2*cm
                c.drawString(2*cm, y_pos, f"Question {q}: Réponse étudiant...")

            # Nouvelle page
            c.showPage()

    c.save()
    print(f"✅ PDF généré : {output_path}")
    print(f"   - Étudiants : {student_count}")
    print(f"   - Pages : {student_count * pages_per_student}")

if __name__ == '__main__':
    import argparse

    parser = argparse.ArgumentParser()
    parser.add_argument('--students', type=int, default=30)
    parser.add_argument('--pages', type=int, default=4)
    parser.add_argument('--format', choices=['A3', 'A4'], default='A3')
    parser.add_argument('--output', default='test_exam.pdf')

    args = parser.parse_args()

    generate_test_pdf(args.students, args.pages, args.output, args.format)
```

**Usage** :

```bash
# Générer PDF test 30 étudiants, 4 pages chacun (A3)
python generate_test_pdf.py --students 30 --pages 4 --format A3 --output test_batch_a3.pdf

# Vérifier
pdfinfo test_batch_a3.pdf
```

## 📝 Conclusion

Le format PDF des examens doit respecter des spécifications strictes (A3 300 DPI, niveaux de gris) pour garantir un OCR optimal. Les outils de validation et correction permettent de préparer des PDF conformes avant upload.

**Points clés** :
- Format A3 recto-verso (recommandé)
- Résolution 300 DPI
- Niveaux de gris 8-bit
- Header 5 cm (nom, prénom, date naissance)
- Taille < 100 MB
- Validation avant upload
