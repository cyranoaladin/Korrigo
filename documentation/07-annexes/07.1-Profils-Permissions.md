## 🎯 Vue d'Ensemble

Korrigo gère **3 profils utilisateurs principaux** avec des permissions granulaires basées sur le système de permissions Django.

### Hiérarchie des Profils

```
┌─────────────────────────────────────┐
│         ADMIN (Superuser)           │
│   • Accès complet                   │
│   • Gestion utilisateurs            │
│   • Toutes opérations               │
└──────────────┬──────────────────────┘
               │
    ┌──────────┴────────────┐
    │                       │
┌───▼──────────────┐  ┌────▼─────────────┐
│  TEACHER         │  │  STUDENT         │
│  • is_staff=True │  │  • is_staff=False│
│  • Correction    │  │  • Consultation  │
└──────────────────┘  └──────────────────┘
```

## 👤 Profil 1 : Admin (Administrateur)

### Caractéristiques

- **Django** : `is_superuser=True`, `is_staff=True`
- **Groupes** : `admin`, `teacher` (hérite permissions enseignant)
- **Accès** : Complet sur toutes les ressources

### Permissions

| Permission | Description |
|------------|-------------|
| ✅ **create_exam** | Créer un examen |
| ✅ **delete_exam** | Supprimer un examen |
| ✅ **upload_scans** | Upload PDF et CSV |
| ✅ **assign_corrector** | Assigner correcteurs aux copies |
| ✅ **manage_users** | Créer/modifier/supprimer utilisateurs |
| ✅ **view_all_copies** | Voir toutes les copies (tous examens) |
| ✅ **grade_any_copy** | Corriger n'importe quelle copie |
| ✅ **finalize_exam** | Publier résultats |
| ✅ **export_results** | Exporter statistiques |
| ✅ **access_django_admin** | Accès Django Admin (`/admin/`) |
| ✅ **unlock_copy** | Déverrouiller copie verrouillée |
| ✅ **override_identification** | Forcer identification manuelle |

### Workflows Autorisés

1. **Création d'Examen** :
   - Créer examen
   - Upload PDF + CSV
   - Lancer traitement batch
   - Gérer identification des copies
   - Assigner correcteurs

2. **Correction** :
   - Corriger toutes les copies (assignées ou non)
   - Déverrouiller copies finalisées

3. **Gestion Utilisateurs** :
   - Créer comptes enseignants
   - Créer comptes étudiants
   - Réinitialiser mots de passe
   - Gérer groupes et permissions

4. **Finalisation** :
   - Publier résultats
   - Exporter statistiques
   - Archiver examens

## 👨‍🏫 Profil 2 : Teacher (Enseignant)

### Caractéristiques

- **Django** : `is_staff=True`, `is_superuser=False`
- **Groupes** : `teacher`
- **Accès** : Limité aux copies assignées

### Permissions

| Permission | Description |
|------------|-------------|
| ✅ **view_assigned_copies** | Voir ses copies assignées uniquement |
| ✅ **grade_copies** | Corriger copies assignées |
| ✅ **annotate_copies** | Ajouter annotations PDF |
| ✅ **lock_copy** | Verrouiller copie après correction |
| ✅ **select_ocr_candidate** | Sélectionner candidat (mode SEMI-AUTO) |
| ✅ **manual_assign_student** | Assignation manuelle (mode MANUAL) |
| ✅ **view_exam_details** | Voir détails examens assignés |
| ❌ **create_exam** | ❌ Ne peut pas créer examen |
| ❌ **assign_corrector** | ❌ Ne peut pas assigner correcteurs |
| ❌ **finalize_exam** | ❌ Ne peut pas publier résultats |
| ❌ **access_django_admin** | ❌ Pas d'accès Django Admin |
| ❌ **unlock_copy** | ❌ Ne peut pas déverrouiller copie finalisée |

### Workflows Autorisés

1. **Correction** :
   - Lister ses copies assignées
   - Ouvrir copie
   - Annoter PDF
   - Attribuer notes par question
   - Sauvegarder (auto-save)
   - Finaliser et verrouiller

2. **Identification** (si copies non identifiées) :
   - Voir candidats OCR (mode SEMI-AUTO)
   - Sélectionner bon étudiant parmi top-5
   - Rechercher manuellement (mode MANUAL)

### Restrictions

- **Ne peut pas** :
  - Voir copies d'autres correcteurs
  - Modifier copie verrouillée
  - Créer/supprimer examens
  - Gérer utilisateurs
  - Publier résultats

## 👨‍🎓 Profil 3 : Student (Étudiant)

### Caractéristiques

- **Django** : `is_staff=False`, `is_superuser=False`
- **Groupes** : Aucun
- **Accès** : Consultation résultats uniquement
- **Authentification** : 2 méthodes
  - Standard : `username` + `password`
  - Alternative : `email` + `date_of_birth`

### Permissions

| Permission | Description |
|------------|-------------|
| ✅ **view_own_results** | Voir ses propres résultats |
| ✅ **view_own_copies** | Voir ses copies corrigées (publiées) |
| ✅ **download_copy_pdf** | Télécharger PDF de sa copie |
| ❌ **view_others_copies** | ❌ Ne peut pas voir copies d'autres étudiants |
| ❌ **grade_copies** | ❌ Ne peut pas corriger |
| ❌ **create_exam** | ❌ Ne peut pas créer examen |
| ❌ **access_admin** | ❌ Aucun accès admin |

### Workflows Autorisés

1. **Authentification** :
   - Login via email + date de naissance
   - OU login standard (si User créé)

2. **Consultation** :
   - Liste de ses examens
   - Voir copie corrigée (si publiée)
   - Voir notes par question
   - Voir annotations enseignant
   - Télécharger PDF

### Restrictions

- **Ne peut voir que** :
  - Ses propres copies
  - Examens publiés uniquement
  - Pas d'accès pendant correction

- **Ne peut pas** :
  - Voir copies en cours de correction
  - Modifier quoi que ce soit
  - Voir copies d'autres étudiants
  - Accéder aux interfaces admin/teacher

def is_student(user):

class IsStudent(BasePermission):

## 🔐 Groupes Django

### Configuration Groupes

**Fichier** : `backend/core/management/commands/setup_groups.py`

```python
from django.core.management.base import BaseCommand
from django.contrib.auth.models import Group, Permission

class Command(BaseCommand):
    help = 'Setup default groups and permissions'

    def handle(self, *args, **options):
        # Groupe Teacher
        teacher_group, created = Group.objects.get_or_create(name='teacher')

        if created:
            permissions = [
                'view_copy',
                'change_copy',
                'add_grade',
                'change_grade',
                'add_annotation',
                'change_annotation',
            ]

            for perm_code in permissions:
                try:
                    perm = Permission.objects.get(codename=perm_code)
                    teacher_group.permissions.add(perm)
                except Permission.DoesNotExist:
                    self.stdout.write(f'Permission {perm_code} not found')

            self.stdout.write(self.style.SUCCESS('Teacher group created'))

        # Groupe Admin
        admin_group, created = Group.objects.get_or_create(name='admin')

        if created:
            # Admin hérite toutes permissions teacher
            admin_group.permissions.set(teacher_group.permissions.all())

            # + Permissions admin spécifiques
            admin_permissions = [
                'add_exam',
                'change_exam',
                'delete_exam',
                'add_user',
                'change_user',
                'delete_user',
            ]

            for perm_code in admin_permissions:
                try:
                    perm = Permission.objects.get(codename=perm_code)
                    admin_group.permissions.add(perm)
                except Permission.DoesNotExist:
                    pass

            self.stdout.write(self.style.SUCCESS('Admin group created'))
```

## 🔒 Vérifications de Permissions

### Backend (DRF ViewSet)

```python
from rest_framework import viewsets
from rest_framework.permissions import IsAuthenticated
from core.permissions import IsTeacher, IsAssignedCorrector

class CopyViewSet(viewsets.ModelViewSet):
    """
    ViewSet avec permissions granulaires.
    """
    permission_classes = [IsAuthenticated]

    def get_permissions(self):
        """Permissions dynamiques selon action."""

        if self.action in ['list', 'retrieve']:
            # Lecture: teacher ou admin
            return [IsAuthenticated(), IsTeacher()]

        elif self.action in ['update', 'partial_update']:
            # Modification: correcteur assigné uniquement
            return [IsAuthenticated(), IsAssignedCorrector()]

        elif self.action == 'destroy':
            # Suppression: admin uniquement
            return [IsAuthenticated(), IsAdmin()]

        return super().get_permissions()

    def get_queryset(self):
        """Filtrer selon profil."""

        user = self.request.user

        if user.is_superuser:
            # Admin voit tout
            return Copy.objects.all()

        elif user.is_staff:
            # Teacher voit ses copies assignées
            return Copy.objects.filter(corrector=user)

        else:
            # Student voit ses copies publiées
            return Copy.objects.filter(
                student__user=user,
                status=Copy.Status.PUBLISHED
            )
```
